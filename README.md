# Kiếm Lai · Tu Tiên Ký (劍來 · 修仙記)

> Game 2D Xianxia Idle / Incremental RPG phong cách Cổ Phong Thủy Mặc phỏng theo tiểu thuyết tiên hiệp đỉnh cao **Kiếm Lai (Phong Hỏa Hí Chư Hầu)** & gameplay **Quỷ Cốc Bát Hoang**.
> Web-first, Single-player, PWA Offline, lưu trữ cục bộ (Local-First IndexedDB & LocalStorage), Zero Data Loss.

---

## 🌟 Tính Năng Nổi Bật (Features)

### 1. Hệ Thống "Khởi Lập Đạo Đồ" (Origin Cultivation Path)
Người chơi khi bước vào thế giới tu chân được tự do định đoạt con đường đại đạo khởi đầu:
- **👊 Thuần Túy Võ Phu (Martial Artist)**:
  - Đi theo **11 Cảnh Giới Võ Đạo** (Nê Phôi $\rightarrow$ Kim Thân $\rightarrow$ Sơn Điên $\rightarrow$ Chỉ Cảnh $\rightarrow$ Võ Thần).
  - Không mượn nửa điểm thiên địa linh khí, chỉ dùng **Khí Huyết & Quyền Ý**.
  - Bấm **"Luyện Quyền"** tích lũy quyền lực; thực chiến trong Hành Tẩu tự động nuôi dưỡng Hám Sơn Quyền Ý.
  - **Miễn nhiễm hoàn toàn Lôi Kiếp Thiên Phạt** (trời đất không phạt kẻ không cướp đoạt linh khí).
  - Phong cách chiến đấu **CẬN CHIẾN (Melee)**: Kích hoạt cơ chế độc bản **"Áp Chế 10 Trượng"** tăng trọn vẹn **+35% sát thương** khi áp sát kẻ địch; hiệu ứng quyền kình sóng xung kích nổ tung trên thân thể quái vật (màn hình tĩnh lặng, không rung giật nhức mắt).
- **📜 Luyện Khí Tiên Đạo (Qi Cultivator)**:
  - Leo qua **15 Cảnh Giới Luyện Khí Sĩ Kiếm Lai** (Đồng Bì $\rightarrow$ Động Phủ $\rightarrow$ Kim Đan $\rightarrow$ Nguyên Anh $\rightarrow$ Ngọc Phác $\rightarrow$ Phi Thăng $\rightarrow$ Thập Ngũ Cảnh).
  - Ngồi thiền tụ khí cướp đoạt tạo hóa trời đất, vượt qua sinh tử quan **Long Môn Cảnh** và độ **Lôi Kiếp Phạt Tội**.
  - Phong cách chiến đấu **TẦM XA (Ranged)**: Đứng trấn thủ từ xa, phóng xuất Bản Mệnh Phi Kiếm hoàng kim hoặc Phù Lục xé gió cắm thẳng vào quái vật.
- **🌟 Kiếm Võ Song Tu (Dual Cultivation - Trần Bình An Style)**:
  - Đạo Cốt Huyền Thoại mở khóa qua hệ thống **Luân Hồi (Legacy)** ở Kiếp 2 trở đi.
  - Vừa uẩn dưỡng Hám Sơn Quyền Ý cận chiến, vừa phóng Bản Mệnh Phi Kiếm sát phạt tầm xa!

### 2. Lục Đại Hệ Phái Chân Truyền (6 Factions)
Chuẩn theo Game Design Document nguyên tác:
1. ⚔️ **Kiếm Tu** *(Kiếm Khí Trường Thành)*: Carry / Burst DPS Tầm Xa. Bản Mệnh Phi Kiếm bạo kích cực đại, xuyên giáp lấy mạng đổi mạng.
2. 👊 **Thuần Võ Phu** *(Thuần Túy Võ Đạo)*: Bruiser / Juggernaut Cận Chiến. Hám Sơn Quyền Ý, máu dày giáp cứng, áp chế 10 trượng.
3. 📿 **Đạo Gia Phương Sĩ** *(Bạch Ngọc Kinh)*: Mage / AoE Tầm Xa. Phù Trận Ngũ Lôi tê liệt và Huyền Vũ Hộ Thân Phù (khiên 25% HP).
4. 📖 **Nho Sĩ** *(Văn Miếu / Sơn Nhai)*: Control / Buffer Tầm Xa. Khẩu Hàm Thiên Hiến (Ngôn Xuất Pháp Tùy), áp chế công thủ địch, tăng cơ duyên.
5. 🚩 **Binh Gia** *(Đại Lệ Quân Đội)*: Vanguard Berserker Cận Chiến. Hút máu (Lifesteal) và Cuồng Nộ bộc phát công kích khi thấp máu.
6. ⚙️ **Mặc Gia Cơ Quan Sư** *(Bách Gia Chư Tử)*: Tactical / Siege Tầm Trung. Cự Giáp & Khôi Lỗi Thú gánh đòn, bào mòn vĩnh viễn giáp Boss.

### 3. Hành Tẩu & Sân Đấu Thủy Mặc (Journey Stage)
- Bản đồ các vùng đất chuẩn Kiếm Lai: *Ly Châu Động Thiên (Lò gốm ngõ Nê Bình) $\rightarrow$ Thư Giản Hồ $\rightarrow$ Kiếm Khí Trường Thành $\rightarrow$ Man Hoang Thiên Hạ*.
- Quái vật và Đại Yêu có tranh vẽ lập hội thủy mặc cổ phong đặc sắc.
- Hiệu ứng chiến đấu phân hóa rực rỡ: Animation lướt đòn cận chiến (`journey-melee-rush`), vòng sóng xung kích Khí Huyết đỏ rực, tia Phi Kiếm hoàng kim (`flying-sword-bolt`).

### 4. Hệ Thống Lưu Trữ An Toàn Tuyệt Đối (Save v10)
- Kiến trúc Local-First, chuỗi migration tự động từ `v1` đến `v10` bảo toàn 100% dữ liệu người chơi cũ.
- Tự động tích lũy tiến trình treo máy offline (Offline Accumulator lên đến 8 giờ).
- Hỗ trợ Export/Import mã hóa Base64 và sao lưu IndexedDB.

## 🛠️ Công Nghệ & Kiến Trúc (Tech Stack)

- **Frontend Core:** React 19 + TypeScript (Strict Mode) + Vite + Tailwind CSS v4.
- **State Management:** Zustand (Seeded PRNG deterministic, tách biệt hoàn toàn Simulation Engine khỏi View).
- **Audio & Visual:** Web Audio Synthesizer sfx + Ink-Wash Parallax SVG Shaders + CSS GPU-Accelerated Keyframes.
- **Testing Suite:** Vitest (161 tests unit & balance simulation 24h).
- **PWA:** Service Worker offline-ready, cài đặt như Native App trên PC/Mobile.

## 🚀 Hướng Dẫn Cài Đặt & Chạy Dự Án

```bash
# 1. Cài đặt dependencies
pnpm install

# 2. Khởi động môi trường phát triển local
pnpm dev

# 3. Chạy toàn bộ kiểm thử tự động (161 tests)
pnpm test

# 4. Kiểm tra mã nguồn (Linter)
pnpm lint

# 5. Đóng gói sản phẩm (Production Build + PWA)
pnpm build

# 6. Giả lập cân bằng game bot 24h
pnpm sim 24 1        # Bot chơi tích cực (seed 1)
pnpm sim 24 1 passive # Bot cắm máy treo đồ (seed 1)
```

## 📁 Cấu Trúc Mã Nguồn (Directory Structure)

```text
/src
 ├── content/        # Dữ liệu tĩnh (realms, martialRealms, classes, gear, items, recipes, regions...)
 ├── engine/         # Pure Deterministic Simulation (combat, cultivation, journey, save/migrate, tick...)
 ├── lib/            # Tiện ích toán học, formatters, audio sfx, idempotent asset resolver
 ├── store/          # Zustand Store & fixed-step game loop (100ms accumulator)
 ├── ui/             # Giao diện Atomic (atoms, molecules, organisms, screens, silhouettes)
 └── styles/         # Bảng màu Ink-Wash, tokens thủy mặc & animations
/tests               # 32 test suites (Guardrail toán học, Save Migration v1-v10, UI smoke)
/docs                # GDD Kiếm Lai (docs.md), kế hoạch phát triển & walkthrough
```
